Online Marketing – SEO & AI Search Tools

Free Online SEO Tools

Online Marketing provides free online tools for technical SEO, website analysis, search engine investigations and hosting analysis. The tools can be accessed directly without registration.

Linktjekkeren – Link Analysis

Linktjekkeren is a free website analysis tool for examining links, recurring link structures and technical signals relevant to website analysis and link building.

The tool can help identify link relationships and examine technical aspects of websites without requiring specialized software installations.

Google Search – Geographic Search Tool

This free tool allows users to perform Google searches using selected countries, languages, cities and geographic locations.

It is useful for examining differences in search results between geographic markets and investigating local and international search visibility.

Open Google Geographic Search

Robots.txt Validator

The Robots.txt Validator is a free technical tool for analyzing and validating robots.txt files.

It helps examine crawler access rules, directives, sitemap references and potential configuration issues affecting search engines and automated crawlers.

The tool is designed for website administrators, SEO specialists and developers investigating technical crawler accessibility.

Open Robots.txt Validator

IP & Hosting Analysis

IP & Hosting Analysis is a free tool for examining the technical infrastructure behind websites and domain names.

It provides information about IP addresses, reverse DNS, autonomous system numbers (ASN), hosting providers, nameservers, CDN information and related network infrastructure.

The tool can also assist with comparing domains and investigating shared IP network relationships.

Open IP & Hosting Analysis

Software & AI Projects

In addition to the free online tools, Online Marketing develops software for technical SEO, website monitoring, structured data and AI search technology.

AI Discovery Framework

AI Discovery helps websites provide structured and machine-readable information for search engines, AI search systems and automated agents.

The framework generates technical resources that support machine-readable website information, including AI discovery files, structured data, knowledge graph resources and agent-related information.

AI Discovery is available for WordPress and Joomla. A platform-independent standalone edition is also under development.

AI Discovery and software projects

SEO Intelligence

SEO Intelligence provides technical and on-page SEO analysis and optimization tools for WordPress.

The system examines titles, meta descriptions, headings, canonical URLs, internal links, structured data and other technical SEO elements.

It is developed to assist with ongoing website maintenance and SEO improvements.

Webstedslog

Webstedslog provides website monitoring, crawler detection, security logging and IP intelligence for WordPress and Joomla.

The system helps website administrators investigate automated traffic, search engine crawler activity and unusual request patterns.

It also supports technical monitoring and analysis of website traffic at the application level.
